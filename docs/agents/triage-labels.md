# Triage Labels

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Proposal awaiting the owner's review; for phase issues, implementation not yet permitted |
| `needs-info` | `needs-info` | Waiting on the owner for a decision only they can make |
| `ready-for-agent` | `ready-for-agent` | Owner has granted permission; an agent may implement when blockers are closed |
| `ready-for-human` | `ready-for-human` | Requires the owner's hands (accounts, taste decisions, reviews) |
| `wontfix` | `wontfix` | Will not be actioned |

Extra labels used by this repo: `phase` (one per plan phase), `research` (cited source-gathering), `adr` (a decision that needs recording).
